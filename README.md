# Sistema de Gestão de Hotel Sistema de gestão hoteleira em Python, desenvolvido em equipa. Gere quartos de vários tipos (simples, luxo) e reservas de hóspedes. Aplica herança simples e múltipla, polimorfismo, classes abstratas e módulos, com listas, dicionários, tuplos e laços de repetição (for, while).
